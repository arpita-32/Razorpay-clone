Razorpay Clone - Readme
Overview
This project is a responsive clone of the Razorpay website, a popular payment gateway solution in India. The clone includes key sections of the original website such as the navbar, hero section, feature sections, testimonials, and footer.

Features
Responsive Design: Works on mobile, tablet, and desktop screens

Interactive Elements: Hover effects, buttons, and navigation

Modern UI Components:

Feature cards with hover animations

Testimonial slider

Animated company logos section

Multi-column footer

Performance Optimized: Lazy loading for images where appropriate

Technologies Used
HTML5

CSS3 (including CSS Grid and Flexbox)

Feather Icons (for vector icons)

Vanilla JavaScript (minimal for icon functionality)

How to Use
Clone this repository

Open index.html in your browser

No build process or dependencies required (works directly in browser)

Customization
To customize this project:

Replace images in the Images/ folder

Modify colors in the CSS (look for color variables)

Update content in the HTML file
